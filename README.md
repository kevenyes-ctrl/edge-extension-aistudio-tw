# Google AI Studio 繁體中文助手 (Chrome / Edge 擴充功能)

一個為 [Google AI Studio](https://aistudio.google.com/) 打造的繁體中文化瀏覽器擴充功能。採用台灣常用開發與軟體術語校正，讓繁體中文使用者在使用 Gemini 進行提示詞測試、模型參數調整與應用程式建構時，享有更親切流暢的開發體驗。

---

### 專案特色

- **在地化台灣用語**：全面校正為台灣常用詞彙（例如：提示詞、專案、執行、預設、Token、說明文件、儲存庫等）。
- **保留原始提示與對話**：僅翻譯 AI Studio 平台功能選單、按鈕、模型參數說明與 Tooltips，絕對不會干擾使用者輸入的 Prompt、系統指令（System Instructions）或對話產出內容。
- **純前端輕量執行**：無任何外部伺服器依賴，純 JavaScript DOM 動態監聽，即時替換介面字串。
- **無資安疑慮**：不收集任何使用者資訊，不儲存、不讀取使用者的 API 金鑰或對話紀錄。

---

### 安裝步驟

#### 1. 下載專案檔案
- 點擊本儲存庫右上角的 **Code** 按鈕，選擇 **Download ZIP**。
- 將下載的壓縮檔解壓縮至電腦中的固定資料夾（建議保留在不會隨意移動或刪除的路徑）。

#### 2. 於 Chrome / Edge 瀏覽器載入
1. 開啟 Chrome 瀏覽器，於網址列輸入 `chrome://extensions/` 並按 Enter（Edge 請輸入 `edge://extensions/`）。
2. 開啟右上角的**「開發人員模式」**（Developer mode）開關。
3. 點擊左上角的**「載入未封裝項目」**（Load unpacked）按鈕。
4. 選取剛剛解壓縮的資料夾。
5. 前往 [Google AI Studio](https://aistudio.google.com/) 重新整理網頁，即可看到繁體中文介面。
